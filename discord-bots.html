Open-Source Discord Bots

Curated list of awesome open-source Discord Bots

Java Discord API - JDA (GitHub, Documentation, Wiki)

  • LupoBot - An all-in-all Discord bot that offers many cool new features in plugins which you can install to your Discord server
  • Clancy - A Discord Music Bot made in Spring Boot and Java which you can host and run yourself

eris (Github, Website/Documentation)

  • Star [(https://www.star-bot.tk)] - Helping servers grow exponentially with a simple solution. Make your server active and entertain your community with a simple solution.

discord.js (GitHub, Website/Documentation, Guide)

  • Chalda DiscordBot - A chat bot for discord app based off discord.js
  • Heptagram - The open-source discord bot with the goal to be the single needed bot for any server.
  • Evobot - 🤖 EvoBot is a Discord Music Bot built with discord.js & uses Command Handler from discordjs.guide
  • automod-bot - Moderation bot discord.js
  • CalypsoBot - A fully customizable bot built with discord.js
  • Dorito bot - A multipurpose Discord bot with many NSFW and fun commands as well as utility, moderation SFW commands and more.
  • Musicbot - Discord.JS Music Bot
  • discord-music-bot - Node.js / Discord.js / Discord.js-Commando based bot solely for the purpose of playing audio stream to Discord
  • Economybot - Discord.js Economy bot using Quick.db (DJS V11)
  • Komugari - A simple, multi-functional Discord bot written in Discord.js
  • Discord-MusicBot - Very simple discord music bot with the discord.js with Song Name playing. It can able to play music with the song name
  • Discord-Datamining - Datamining Discord changes from the js files
  • discord-giveaway-bot - Very simple giveaway bot made with discord.js
  • 16Bits - Multipurpose Guildbounded Bot with fun, moderation, utilities, animal, etc. commands.

discord.py [DEPRECATED] (GitHub, Website/Documentation, Guide)

Note: This library has been discontinued, it is advised you look into alternatives for using Python for bots!

  • Translator101 - A translator bot made with discord.py and the google-trans library.
  • ServerKit - A general purpose bot that combats bots with paywalled features and helps reduce bots needed in a server.

Discord.NET (GitHub, Website/Documentation, Guide)

  • discord-event-bot - A bot that halps planning events like raids or meetings inside discord.

Feel free to add your Discord Bot. If the library of your Discord Bot doesn’t exist, just add it. You can find more information on contributing here.
